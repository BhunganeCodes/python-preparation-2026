Python Coding Assessment

This is a simple Python assessment project that includes multiple basic algorithmic tasks and unit tests.

## Tasks Implemented

1. **Sum of all numbers from 1 to N**
2. **Reverse a list using a loop**
3. **Remove duplicates from a list**
4. **Generate Fibonacci series up to 10 terms**
5. **Count character frequency in a string**
6. **Find factorial of a number**
7. **Check is number or string is palindrome**
